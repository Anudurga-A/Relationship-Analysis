# Relationship Analysis Using Scatter Plot

## Objective
To understand the relationship between two numerical variables using data visualization.

## Description
This project uses Python, Pandas, and Matplotlib to create a scatter plot and analyze the relationship between study hours and marks.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Steps Performed
1. Imported the required Python libraries.
2. Created a sample dataset containing study hours and marks.
3. Generated a scatter plot.
4. Calculated the correlation between the variables.
5. Identified and documented three observations.

## Observations
1. Study hours and marks show a positive relationship in the sample dataset.
2. Marks generally increase as study hours increase.
3. The scatter plot shows an upward trend.

## Result
A scatter plot was created successfully to visualize and analyze the relationship between study hours and marks.
